# PLAY / LOG — Gaming Catalog

פורטל HTML בעברית לניהול קטלוג משחקי PS4, עם תמיכה בטלפון ובמחשב.

## פתיחה

פתחו את `index.html` בדפדפן. אין צורך בהתקנת ספריות או שרת.
הקטלוג כולל 872 רשומות חבילה מתוך 26 קובצי SQLite שסופקו. גרסאות שונות מוצגות בנפרד.

## יכולות

- חיפוש וסינון A–Z, לפי הורדה, משחק או הערות.
- תיבות סימון ״הורדתי״, ״שיחקתי״ ו״לא מעוניין״ לכל חבילה. ל״לא מעוניין״ ניתן להוסיף סיבה; הסיבה נשמרת גם לאחר ביטול הסימון. סינון עניין מאפשר הכול, הסתרת לא מעוניין, או רק לא מעוניין. הסימון והסיבה נכללים בגיבוי ובסנכרון.
- קישור לחיפוש Google של שם המשחק וקישור לאוסף המתאים ב־Archive.
- הערות, רשמים ועדכונים עם שמירה מיידית בדפדפן.
- ייצוא JSON לגיבוי וייבוא שממזג את העדכון החדש בכל שדה.
- מקום לצ׳יטים עתידיים, ללא מימוש.
- מעבר בין כרטיסיות לרשימה קומפקטית. ברשימה ניתן לפתוח/לסגור כל משחק, או את כל המשחקים בעמוד, ולהשתמש בסימונים גם כשהפרטים סגורים.
- שילוב סינונים לפי הורדה, משחק, הערות ואזור; מיון לפי שם או גודל ואיפוס סינונים בלחיצה.
- מעבר בין עברית (RTL) לאנגלית (LTR), כולל הודעות וחלון הסנכרון. ההערות האישיות ושמות המשחקים אינם מתורגמים.
- השפה, התצוגה, החיפוש והסינונים נשמרים בדפדפן; העדפות התצוגה מקומיות למכשיר ואינן נכללות בסנכרון ההתקדמות.
- שנת יציאה בסוגריים, תמונת עטיפה, ציון מבקרים ותקציר אוטומטי בעברית/אנגלית עם קישורים למקורות. אפשר לסנן לפי שנת יציאה, שנת PS4 כשנמצאה, ושלמות המידע.

## העשרה אוטומטית של המשחקים

```powershell
python -m pip install -r scripts/requirements-metadata.txt
python scripts/enrich_catalog.py --search-missing
python scripts/audit_metadata.py
```

אין צורך במפתח API. הסקריפט קורא את הקטלוג, מתאים שמות לערכי Wikipedia, ומחלץ שנה, תמונה, ציון Metacritic כפי שהוא מופיע בערך, ותקציר קצר המבוסס על הציון ועל אמירות הערכה מפורשות בפרק הביקורות. זו אינה ביקורת אישית או קריאה ידנית של כל ביקורת. שם הערך שזוהה מוצג בפורטל, כדי שאפשר יהיה לזהות גם התאמה שגויה.

הציונים מוצגים עם הפלטפורמה: יש העדפה ל־PS4 כשנמצא ציון מפורש, אחרת מוצגת הפלטפורמה האחרת כפי שנמסרה במקור. ציון שפלטפורמתו לא צוינה מסומן בהתאם. שנת היציאה היא המוקדמת שנמצאה בשדה ההוצאה של הערך המזוהה; שנת PS4 היא אופציונלית. באוספים ורימאסטרים זהות הערך קובעת לאיזו מהדורה מתייחסים הנתונים.

המקור אינו מכסה כל משחק. רשומות שלא הותאמו או שדות שלא נמצאו מסומנים כחסרים, ואינם מקבלים שנה, תמונה או ציון מומצאים. `data/metadata-report.json` מפרט את החוסרים. `data/metadata-audit.json` כולל תוצאת בדיקה לכל אחת מרשומות הקטלוג. בדיקת הביקורת מחזירה כישלון עבור מבנה נתונים/תאריכים/ציונים לא תקינים; חוסר מידע מדווח בנפרד.

תוצאת הריצה ב־22 בספטמבר 2026: נבדקו 872 רשומות; נמצאה שנה ל־777, תמונה ל־766, ציון ל־719 ותקציר ל־733. ל־709 יש את כל ארבעת השדות; שנת PS4 אופציונלית נמצאה ל־605. 95 רשומות לא הותאמו אוטומטית לערך משחק. [דו״ח הבדיקה והחוסרים](data/metadata-audit.md) מפרט את התוצאה ללא הסתרת החוסרים.

הבקשות נשמרות במטמון מקומי שאינו מועלה ל־Git. יש מרווח של חמש שניות בין בקשות חדשות, ועצירה של האיסוף במקרה של שגיאת רשת/הגבלת קצב. הרצה חוזרת ממשיכה מהמטמון. אפשר להריץ `python scripts/enrich_catalog.py --offline` לבנייה מחדש ללא גישה לרשת. מידע קיים אינו נמחק רק משום שבקשת רשת נכשלה.

להתאמות שמות ניתן לערוך את `scripts/metadata-titles.json`. הסקריפט אינו משנה מזהי משחקים, קובצי SQLite, סימונים או הערות. נתוני העשרה נשמרים בנפרד ב־`data/metadata.js`. התמונות נטענות מ־Wikimedia לפי הצורך; ללא רשת מוצגת אות המשחק כחלופה.

בדיקות חילוץ: `python scripts/test_metadata.py`. פרטי ייחוס ותמונות: [METADATA-SOURCES.md](METADATA-SOURCES.md).

## שמירה וסנכרון

השמירה המקומית משתמשת ב־localStorage. מחיקת נתוני הדפדפן מוחקת אותה; מומלץ להוריד גיבוי. שגיאת שמירה מוצגת במפורש. נתונים פגומים קיימים אינם נדרסים אוטומטית.

כל כתובת אתר, דפדפן ופרופיל מחזיקים שמירה נפרדת. לפני מעבר מקובץ מקומי לאתר, ייצאו גיבוי וייבאו אותו באתר החדש. במצב גלישה פרטית השמירה עלולה להימחק בסגירה.

### הפעלת סנכרון בין מכשירים

1. לחצו על ״סנכרון״ ופתחו את הקישור ליצירת אסימון GitHub עם הרשאת `gist` בלבד.
2. הזינו את האסימון בפורטל עצמו. במכשיר הראשון לחצו על ״יצירת Gist חדש״.
3. העתיקו את מזהה ה־Gist המוצג. בכל מכשיר נוסף הזינו אסימון ומזהה זה ולחצו ״חיבור וסנכרון״.

האסימון נשמר למשך הלשונית בלבד כברירת מחדל. האפשרות ״זכור אסימון״ שומרת אותו בדפדפן ללא הצפנה ומתאימה למכשיר אישי בלבד. אסימונים אינם נכללים בגיבוי. Gist סודי אינו פרטי: כל מי שמחזיק בקישור יכול לקרוא אותו.

שינויים נשמרים מקומית מיד ומסונכרנים כעבור כ־2 שניות; עדכונים ממכשירים אחרים נקראים גם כל 45 שניות כשהעמוד גלוי. ללא חיבור, השמירה המקומית ממשיכה והסנכרון מתחדש בחזרת החיבור. סגירת הלשונית לפני סיום הסנכרון משאירה את השינוי מקומי עד לפתיחה וחיבור מחדש.

כל לשונית כותבת קובץ נפרד ב־Gist כדי ששני מכשירים לא ידרסו זה את זה. הקריאה ממזגת את כל הקבצים לפי זמן עדכון בכל שדה. אם מגיעים למגבלת גודל/מספר קבצים, מופיעה הודעה במקום לכתוב נתונים חלקיים; ניתן לייצא גיבוי, ליצור Gist חדש ולעדכן את המזהה במכשירים האחרים. ההיסטוריה הישנה נשארת ב־GitHub.

API והרשאות: [תיעוד GitHub Gists](https://docs.github.com/en/rest/gists/gists).

מיזוג גיבויים מבוסס על זמן העדכון של כל שדה. התנגשות באותו שדה משאירה את העדכון המאוחר יותר, ולכן כדאי לייצא גיבוי לפני ייבוא. השעונים במכשירים צריכים להיות מכוונים.

## עדכון הקטלוג

```powershell
python scripts/import_catalog.py "C:\path\to\sqlite"
```

הסקריפט קורא את מסדי הנתונים במצב קריאה בלבד, ללא ביקור באתר. הוא מייצא רק שמות חבילות, גרסה, אזור, גודל וקישור לאוסף אל `data/catalog.js`. קובצי SQLite וכותרות הבקשות המקוריות אינם נכללים במאגר. מזהה הרשומה נגזר משם האוסף ושם הקובץ; שינוי גרסה יוצר רשומה חדשה ללא העברת סטטוס אוטומטית.

## GitHub Pages

לאחר העלאת הקוד, ב־Settings → Pages בחרו Deploy from a branch, את ענף `main` ואת התיקייה `/ (root)`. אם GitHub Pages זמין למאגר, האתר יהיה בכתובת `https://amirke.github.io/GamingCatalog/`.

פרסום הקוד אינו מפרסם את הסימונים וההערות האישיים שנשמרים בדפדפן.

## בדיקות שבוצעו

בדיקת דפדפן אוטומטית ב־Microsoft Edge: שמירת שני הסימונים והערות אחרי רענון, ייצוא/ייבוא גיבוי, סינון סטטוס, 12 רשומות באות U, תצוגה ברוחב 390 פיקסלים ללא גלילה אופקית, והיעדר שגיאות JavaScript. בוצעה גם בדיקה חזותית של צילום מסך במחשב.

הסנכרון נבדק מול API מדומה: יצירת Gist סודי, מיזוג בין שני מכשירים, שינויים מקבילים בשדות שונים, שמירת אסימון למשך הלשונית בלבד, עבודה ללא רשת וחידוש סנכרון. בדיקה מול חשבון GitHub אמיתי דורשת הזנת אסימון בפורטל ולא בוצעה במהלך הפיתוח.

תצוגת הרשימה והשפות נבדקו ב־Edge: פתיחה וסגירה באמצעות מקלדת, פתיחה/סגירה לכל העמוד, שימור הערות וסימונים במעבר שפה, שילוב סינונים, סינון אזור, מיון גודל, תרגום חלון הסנכרון והודעות אימות, שמירת העדפות ותצוגה בטלפון בשתי השפות.

קטעי ביקורת מקוריים מוצגים באנגלית עם שם המקור וקישור, לצד התקצירים האוטומטיים בשפת הממשק. קטעי Wikipedia מציגים את דיון הביקורות; קטעי מבקרים אחרים מוגבלים ל־24 מילים ומקשרים לביקורת המלאה. אין להציג תקציר ניקוד כתחליף לביקורת כתובה.

להשלמה ממקור נוסף (לאחר העשרת Wikipedia):

```powershell
python scripts/supplement_metadata.py --cache-dir .cache/critics --wiki-cache .cache/metadata
python scripts/audit_metadata.py
```

תוספות נשמרות ב־`data/metadata-supplements.json` ומוחלות מחדש גם בבנייה חוזרת. התאמת שמות מחמירה; חוסר או התאמה לא ודאית נשארים גלויים בדוח. לחיצה על תמונת משחק פותחת תצוגה מוגדלת; אפשר לסגור עם Escape, כפתור הסגירה או לחיצה מחוץ לתמונה.

## ביקורות בעברית

ביקורות מערכת מ־GamePro ו־Vgames מוצגות בראש אזור הביקורות, עם קטע קצר או תמצית, קישור לביקורת המלאה וציון כשנמצא. אלו אינם דיונים מפורומים. הוספנו סינון ״יש ביקורת בעברית״ / ״ללא ביקורת בעברית״. גם בממשק באנגלית התוכן המקורי בעברית נשאר בעברית. הביקורות עשויות להתייחס לגרסה אחרת של המשחק; כותרת הביקורת והפלטפורמה שנמצאה מוצגות ליד המקור.

```powershell
python scripts/enrich_hebrew_reviews.py --cache-dir .cache/hebrew-reviews
python scripts/audit_metadata.py
```

הסקריפט משתמש בארכיון הביקורות הציבורי של GamePro ובמקורות Vgames שנבדקו ונשמרו ב־`scripts/hebrew-review-sources.json`. הוא פוסל סיכומי ביקורות וכתבות על ביקורת של אתר אחר. ההתאמה מחמירה ואינה מצמידה ביקורת על משחק המשך למשחק המקורי. `data/hebrew-review-report.json` מפרט היכן טרם נמצאה ביקורת בעברית.

השדות ״לא מעוניין״ והסיבה נבדקו בשמירה אחרי רענון, ביטול/החזרת הסימון, גיבוי/ייבוא, סינונים משולבים, אנגלית, טלפון וסנכרון בין שני דפדפנים מול API מדומה. הביקורות בעברית והסינון נבדקו בכרטיסיות וברשימה.

ניתן לסמן גם ״מעוניין״ (Interested), להוסיף טקסט חופשי ולסנן לפי הסימון. הטקסט נשמר גם כאשר מבטלים את הסימון, ונכלל בגיבוי ובסנכרון יחד עם שאר השדות.

## ז׳אנרים

כל משחק מציג תגיות ז׳אנר בעברית או באנגלית, ויכול להשתייך לכמה ז׳אנרים. הסינון ״ז׳אנר״ מתאים משחק אם הוא שייך לז׳אנר שנבחר, וניתן לשלב אותו עם יתר הסינונים. הסינון נשמר בדפדפן. ״ז׳אנר לא נמצא״ מציג רשומות שטרם סווגו. קישור ליד המשחק מפנה למקור הסיווג.

```powershell
python scripts/enrich_genres.py --wiki-cache .metadata-cache --critic-cache .cache/critics
```

הסקריפט משתמש במקורות שנשמרו בסקריפטי ההעשרה הקודמים. הוא ממפה ז׳אנרים מהמקור לקטגוריות אחידות ב־`data/genres.js`; אינו מסיק ז׳אנר משם המשחק. התאמות למהדורות ואוספים נמצאות ב־`scripts/genre-sources.json`, עם המקור ובסיס ההתאמה. סיווג הרחבות מבוסס על משחק הבסיס. `data/genre-report.json` בודק את הכיסוי לכל רשומות הקטלוג ומפרט חוסרים.
